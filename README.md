# Karolina Ceglarek — Florystyka & Wedding Planning 🌸💍

Profesjonalna strona portfolio oraz wizytówka internetowa dla marki **Karolina Ceglarek — Florystyka & Wedding Planning**, specjalizującej się w kompleksowej oprawie florystycznej ceremonii ślubnych, przyjęć weselnych oraz koordynacji i dekoracji eventowych.

---

## 🌿 O projekcie

Strona została zaprojektowana i wdrożona z myślą o elegancji, wysokiej estetyce wizualnej (stylistyka edytorialna, ciepła paleta barw, subtelna typografia) oraz płynnym doświadczeniu użytkownika (*mobile-first*).

### Główne podstrony i sekcje:
* **Strona główna (`index.html`)**:
  * Efektowny baner powitalny (Hero section) z dynamicznymi akcentami
  * Płynny pasek wyróżnień (*ticker track*)
  * O marce oraz kluczowe statystyki realizacji
  * Prezentacja wybranych projektów i aranżacji florystycznych
  * Zakres usług: kompleksowa florystyka ślubna, bukiety, dekoracje kościołów i sal weselnych, wedding planning
  * Etapy współpracy krok po kroku
  * Formularz i dane kontaktowe
* **Portfolio (`portfolio.html`)**:
  * Szczegółowa galeria kompozycji kwiatowych, opraw stołów i unikalnych projektów okolicznościowych
* **Poznaj mnie (`poznaj-mnie.html`)**:
  * Osobista historia florystki, filozofia pracy z kwiatami oraz wartości przyświecające każdej realizacji

---

## 🛠️ Technologie

Projekt oparty jest na nowoczesnym i zoptymalizowanym stosie technologicznym:

* **React 19** – nowoczesna warstwa widoków i interaktywnych komponentów UI
* **Tailwind CSS v4** – najnowszy silnik utility-first CSS z paletą barw OKLCH i customowymi zmiennymi motywu (`--plum`, `--wine`, `--paper`, `--linen`, `--moss`, `--gold`)
* **Typografia**:
  * *Playfair Display* – eleganckie nagłówki w stylu haute-couture
  * *DM Sans* – czytelny krój bezszeryfowy dla treści
  * *DM Mono* – subtelne metadane, etykiety i akcenty techniczne
* **Vite / ES Modules** – szybki bundling i zoptymalizowany build produkcyjny
* **Hosting**: Cloudflare Pages / GitHub Pages
